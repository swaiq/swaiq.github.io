# نشر دعوة «سوة» على GitHub Pages والحصول على رابط واتساب

هذا الدليل يشرح كيف ترفع مجلد المشروع مرة واحدة، ثم تُصدر رابط دعوة جاهزًا للإرسال في واتساب.

---

## ١) إنشاء حساب ومستودع

1. ادخل إلى <https://github.com> وأنشئ حسابًا (مجاني) إن لم يكن لديك.
2. من الأعلى اضغط **+** ثم **New repository**.
3. الاسم: `maazoom` — النوع: **Public** (شرط أن تكون Pages مجانية).
4. اضغط **Create repository**.

## ٢) رفع الملفات

1. في صفحة المستودع اضغط **Add file → Upload files**.
2. اسحب **محتويات** مجلد `maazoom` كلها (لا المجلد نفسه):
   `index.html`، `ring_gallery_window_lighting.html`، `template-view.html`، `reels.html`، `box-preview.html`، وملفات الـ mp4.
3. اضغط **Commit changes**.

## ٣) تفعيل الصفحات (Pages)

1. **Settings** (في المستودع) → **Pages** من القائمة اليسرى.
2. تحت **Build and deployment** اختر **Source: Deploy from a branch**.
3. **Branch:** `main` — **Folder:** `/ (root)` ثم **Save**.
4. انتظر دقيقة إلى دقيقتين، ثم حدّث الصفحة. سيظهر الرابط:

```
https://USERNAME.github.io/maazoom/
```

> استبدل `USERNAME` باسم حسابك. الواجهة تفتح على `index.html`، والدعوة على:
> `https://USERNAME.github.io/maazoom/ring_gallery_window_lighting.html`

## ٤) إصدار رابط الدعوة بعد التعديل

1. افتح الدعوة من **رابط GitHub Pages** (مهم: ليس من الملف على جهازك).
2. عدّل كل ما تريد بزر **«✎ تعديل الدعوة»**.
3. اضغط زر **«🔗 رابط»** في أعلى لوحة التعديل.
4. سيظهر رابط النشر تلقائيًا في الحقل الأول. اضغط **«📋 نسخ الرابط»** أو **«واتساب»** مباشرة.

الرابط الناتج يحمل كل التعديلات داخله، وشكله:

```
https://USERNAME.github.io/maazoom/ring_gallery_window_lighting.html#d=zH4sIA...
```

## ٥) ملاحظات مهمة

- **كل تعديل = رابط جديد.** الرابط نسخة مجمّدة من لحظة توليده؛ الروابط القديمة تبقى كما هي.
- **لا تستخدم مختصرات روابط تحذف الجزء بعد `#`**، وإلا تفتح الدعوة بالإعدادات الافتراضية.
- **الصور** هي أكبر سبب لطول الرابط. الحد العملي لرسالة واتساب نحو ٦٥٬٠٠٠ حرف؛ المؤشر داخل النافذة يحذّرك، ويمكنك إلغاء «تضمين الصور» ليصير الرابط قصيرًا (الصور الافتراضية للغرفة تبقى كما هي).
- **الضيف لا يستطيع التعديل**: زر التعديل يختفي في وضع الرابط، ولا تُحفظ نسخته في جهازه.
- **الرابط عام**: أي شخص لديه الرابط يفتح الدعوة، لذا لا تضع فيه معلومات لا تريد مشاركتها.
- **معاينة واتساب**: العنوان والوصف يُقرآن من وسوم `og:` داخل الملف. لتغيير اسم العروس/العريس في المعاينة، عدّل الأسطر قرب بداية الملف:
  ```html
  <meta property="og:title" content="دعوة خطوبة — اضغط لفتح الصندوق">
  <meta property="og:description" content="دعوة تفاعلية ثلاثية الأبعاد: افتح صندوق الخاتم واقرأ الدعوة.">
  ```
  (اختياري) لدعم صورة معاينة: ارفع صورة `cover.jpg` بجانب الملفات وأضف
  `<meta property="og:image" content="https://USERNAME.github.io/maazoom/cover.jpg">`
  — يجب أن يكون الرابط كاملًا ومطلقًا.

## ٦) دومين خاص (اختياري)

**Settings → Pages → Custom domain**، ثم أضف سجل `CNAME` عند مزوّد الدومين يشير إلى `USERNAME.github.io`.

---

## للنشر على استضافة عادية (cPanel / FTP)

ارفع نفس الملفات إلى مجلد الموقع (مثل `public_html/maazoom/`)، وستعمل بنفس الطريقة. لا تحتاج PHP ولا قاعدة بيانات.

## بديل: معاينة محلية قبل النشر

```powershell
python -m http.server 8799 --directory "E:\apps\New folder\maazoom"
```

ثم افتح: <http://127.0.0.1:8799/ring_gallery_window_lighting.html>

> عند المعاينة المحلية يكون رابط النشر فارغًا؛ الصق رابط GitHub Pages يدويًا في نافذة «🔗 رابط» ليُحفظ ويُستخدم لاحقًا.
